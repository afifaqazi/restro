This is a restaurant management system called Restro, designed and developed by Afifa Qazi as EAD Project.

Please Follow These Steps to Run this Project:
1. Open CMD in the project directory.
2. Type "npm install" and press Enter to install all dependencies.
3. Type "npm run dev" and press Enter to run the project.
4. The project will run on http://localhost:5173/ or any other port number.
